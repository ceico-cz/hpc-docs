# CEICO HPC Services documentation

This repository holds the user documentation for the high-performance computing services
of the [CEICO project](https://ceico.cz/) at the Institute of Physics (FZU) of the Czech
Academy of Sciences.

**Read the documentation at <https://hpc.ceico.cz>.**

## What you will find there

- **Getting started**: how to get an account and log in, from the command line or in the
  browser (JupyterLab and other web applications).
- **Our systems**: the CEICO clusters Phoebe and Koios, and external systems available to
  CEICO members, such as MetaCentrum.
- **Running jobs**: how to submit and monitor computations with the Slurm scheduler, and what to do when a job fails.
- **Software**: available software, Python environments and guides for specific applications.
- **Tips & tricks**: small things that make everyday work on the clusters easier.

## Suggesting a change

Found a mistake or something that is missing? Every page on the site has an edit button
that opens it here on GitHub, where you can propose a correction. You can also
[open an issue](https://github.com/ceico-cz/hpc-docs/issues) describing the problem.

Details for maintainers (local preview, structure, publishing) are in
[CONTRIBUTING.md](CONTRIBUTING.md).
