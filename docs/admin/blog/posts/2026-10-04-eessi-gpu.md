# Phoebe: CUDA software from EESSI works on gpu1 and gpu2

Since 4 October 2026, GPU-enabled software from [EESSI](https://www.eessi.io/docs/) can use
the GPUs on the `rocky10` nodes `gpu1` and `gpu2`. Until then it failed because it could not
find the NVIDIA driver.

<!-- more -->

## How to use it

EESSI is not loaded by default. In a job or an interactive session on the `rocky10`
partition, add its modules and pick a version:

```bash
module use /cvmfs/software.eessi.io/init/modules
module load EESSI/2025.06
module avail
```

`module use` takes the directory, not the `EESSI/<version>.lua` file inside it. On a GPU node
EESSI also lists its CUDA builds. A quick test:

```bash
module load CUDA-Samples
deviceQuery
```

## What works

* EESSI `2023.06`, `2025.06` and `2026.06`: prebuilt CUDA software (for example
  `CUDA-Samples`) runs on the A100s.
* The `CUDA` module itself (`nvcc` and the rest of the toolkit) does not load yet: NVIDIA's
  licence does not allow EESSI to ship it. To compile CUDA code, use the
  [CUDA installed on the nodes](../../../slurm/gpu-jobs.md) instead.
