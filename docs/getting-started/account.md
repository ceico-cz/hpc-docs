# Get an account on Phoebe and Koios

Phoebe and Koios share user accounts, so one account and SSH key work on both clusters.

1. [Create an SSH key pair](ssh-key.md) on the computer you will connect from.
2. Visit or message [Josef](https://www.fzu.cz/lide/ing-josef-dvoracek) with your
   **public** key to set up your account together.
