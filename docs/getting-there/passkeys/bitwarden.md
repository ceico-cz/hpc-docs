# Install Bitwarden in Firefox

Use Bitwarden to store the passkey for the Phoebe portal. This guide uses the Firefox extension.

**1. Install the extension**

Open the Firefox add-ons site, search for **Bitwarden Password Manager**, and install the extension.

![Bitwarden extension in Firefox](../../passkeys/bitwarden-extension.png)

**2. Sign in to Bitwarden**

Open the Bitwarden extension and sign in to your existing Bitwarden account. If you do not have an account yet, create one first.

**3. Continue with the Phoebe passkey setup**

Once Bitwarden is ready, return to the [Phoebe passkey guide](../Passkeys.md) and complete the passkey setup.
