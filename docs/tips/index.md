# Tips and tricks

Optional tweaks to make working on our clusters more comfortable.

* [Bash tweaks](bash-tweaks.md) - make sure `~/.bashrc` is loaded at login, a complete shell
  history, a coloured prompt, Slurm shorthands and other small commands
* [Screen sessions](screen.md) - keep shells running after you disconnect, with several windows
  shown as tabs
* [Short SSH host aliases](ssh-config.md) - type `ssh phoebe` instead of the full host name,
  with the right username even when it differs from the one on your laptop
* [Vim and the mouse](vim.md) - stop Vim from grabbing mouse selections, so you can copy and
  paste with the mouse

Looking for something else? Copying files and reaching the institute network are in
[Getting started](../getting-started/sshfs.md), and software modules are in
[Software](../software/modules.md).
